# HTML/CSS/JavaScript Websites

This directory contains interactive websites built with HTML, CSS, and JavaScript.

## Websites

### 1. Personal Landing Page (`landing-page/`)
A modern, responsive portfolio landing page featuring:
- Animated hero section with gradient background
- About section with interactive cards
- Skills showcase grid
- Contact section with social links
- Smooth scrolling navigation
- Intersection Observer animations
- Fully responsive design

**View:**
Open `landing-page/index.html` in your browser

### 2. Interactive Calculator (`calculator/`)
A fully functional web calculator with:
- Basic operations: addition, subtraction, multiplication, division
- Additional operations: percentage, modulo
- Clean, modern UI with color-coded buttons
- Keyboard support for all operations
- Real-time calculation display
- Number formatting with commas
- Responsive design

**View:**
Open `calculator/index.html` in your browser

**Keyboard Shortcuts:**
- Numbers: 0-9
- Operations: +, -, *, /
- Enter/=: Calculate result
- Escape: Clear
- Backspace: Delete last digit

### 3. Image Gallery (`image-gallery/`)
An interactive image gallery featuring:
- Filterable categories (All, Nature, City, People, Food)
- Responsive grid layout
- Lightbox for full-size image viewing
- Hover effects and animations
- Click to enlarge images
- Keyboard navigation (ESC to close lightbox)
- Uses Lorem Picsum for placeholder images

**View:**
Open `image-gallery/index.html` in your browser

## Features Common to All Websites

- **Responsive Design**: Works on all screen sizes
- **Modern CSS**: Gradients, animations, flexbox, and grid
- **Interactive JavaScript**: Dynamic functionality and user interaction
- **No Dependencies**: Pure HTML, CSS, and JavaScript
- **Clean Code**: Well-organized and commented

## Browser Support

All websites work in modern browsers:
- Chrome/Edge (latest)
- Firefox (latest)
- Safari (latest)

## Customization

Each website can be easily customized:
- Colors: Modify the gradient values and color variables
- Content: Update text and information in HTML
- Layout: Adjust grid and flexbox properties in CSS
- Functionality: Extend JavaScript features as needed
