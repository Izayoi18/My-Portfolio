# Python Applications

This directory contains basic Python applications demonstrating various programming concepts.

## Applications

### 1. Todo List App (`todo_app.py`)
A command-line task manager that allows you to:
- Add new tasks
- List all tasks
- Mark tasks as completed
- Delete tasks
- Persist data in JSON format

**Usage:**
```bash
python3 todo_app.py
```

### 2. Weather App (`weather_app.py`)
A simulated weather application that:
- Displays weather information for various cities
- Shows temperature, conditions, humidity, and wind speed
- Lists available cities

**Usage:**
```bash
python3 weather_app.py
```

### 3. Calculator App (`calculator_app.py`)
A basic calculator with the following operations:
- Addition, Subtraction, Multiplication, Division
- Power calculation
- Square root
- Percentage calculation

**Usage:**
```bash
python3 calculator_app.py
```

## Requirements
- Python 3.6 or higher
- No external dependencies required (uses only standard library)
