# My-Portfolio

A comprehensive portfolio showcasing multiple applications and websites built with Python, PHP, HTML, CSS, and JavaScript.

## 📁 Project Structure

```
My-Portfolio/
├── python-apps/          # Python applications
│   ├── todo_app.py       # Command-line todo list manager
│   ├── weather_app.py    # Weather information app
│   ├── calculator_app.py # Mathematical calculator
│   └── README.md
├── php-apps/             # PHP applications
│   ├── contact_form.php  # Contact form with validation
│   ├── blog_system.php   # Simple blog system
│   └── README.md
└── websites/             # HTML/CSS/JavaScript websites
    ├── landing-page/     # Personal portfolio landing page
    ├── calculator/       # Interactive web calculator
    ├── image-gallery/    # Filterable image gallery
    └── README.md
```

## 🐍 Python Applications

### 1. Todo List App
A command-line task manager with persistent storage using JSON.

**Features:**
- Add, list, complete, and delete tasks
- JSON-based data persistence
- User-friendly CLI interface

**Run:**
```bash
cd python-apps
python3 todo_app.py
```

### 2. Weather App
Simulates weather data for various cities around the world.

**Features:**
- Weather information for multiple cities
- Temperature, conditions, humidity, and wind speed
- Easy-to-use command-line interface

**Run:**
```bash
cd python-apps
python3 weather_app.py
```

### 3. Calculator App
Basic calculator with multiple mathematical operations.

**Features:**
- Basic operations: +, -, ×, ÷
- Advanced: power, square root, percentage
- Error handling for invalid operations

**Run:**
```bash
cd python-apps
python3 calculator_app.py
```

## 🌐 PHP Applications

### 1. Contact Form Handler
A complete contact form with validation and security features.

**Features:**
- Input validation and sanitization
- XSS protection
- Error handling and user feedback
- Logs submissions to file
- Beautiful gradient design

**Run:**
```bash
cd php-apps
php -S localhost:8000 contact_form.php
# Visit http://localhost:8000
```

### 2. Simple Blog System
A lightweight blog with post management.

**Features:**
- Create, view, and delete posts
- Author and view tracking
- JSON-based storage
- Responsive design
- Full blog post view

**Run:**
```bash
cd php-apps
php -S localhost:8001 blog_system.php
# Visit http://localhost:8001
```

## 🛠️ Technologies Used

- **Python 3**: Backend applications with standard library

## 📋 Requirements

### Python Apps
- Python 3.6 or higher
- No external dependencies

### PHP Apps
- PHP 7.0 or higher
- No database required

### Websites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No server required (can open directly in browser)

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/Izayoi18/My-Portfolio.git
cd My-Portfolio
```

2. Choose an application or website to run:
   - For Python apps: Navigate to `python-apps/` and run with Python 3
   - For PHP apps: Navigate to `php-apps/` and use PHP built-in server
   - For websites: Navigate to `websites/` and open HTML files in browser
